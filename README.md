# 个人介绍网页

一个零依赖的单文件个人主页，用 HTML + CSS + 原生 JavaScript 写成。

## 特性

- 深色 / 浅色主题跟随系统
- 响应式布局，适配桌面与移动端
- 滚动入场动画，遵循 `prefers-reduced-motion`
- 语义化标签与无障碍标注

## 本地预览

直接用浏览器打开 `index.html`，或启动本地服务：

```bash
python3 -m http.server 8000
# 访问 http://127.0.0.1:8000/
```

## 自定义

页面内容全部集中在 `index.html` 中，替换以下占位内容即可：

- `你的名字`：姓名（导航、标题、信息栏、页脚）
- `you@example.com`：邮箱
- 头像区块中的 `你`：改为 `<img src="avatar.jpg" alt="头像" />`
- 技能、经历、项目卡片的文案与链接
- 技能卡片上的 `--w` 值：熟练度百分比
